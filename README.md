# Dennis Braun

IT professional from Germany. I build practical self-hosted tools for homes, homelabs, and everyday workflows.

Most of my public work starts with a real problem I run into myself: unreliable internet diagnostics, family planning that should stay private, or small tools that make a setup easier to run. I care about clear UX, local-first data, useful docs, and software that people can operate without needing a SaaS account.

## Focus

- Self-hosted apps for households and homelabs
- Python, Flask, FastAPI, React, Next.js, Docker, SQLite, PostgreSQL
- Home Assistant and local automation
- Monitoring, diagnostics, and practical evidence collection
- Privacy-respecting tools that stay useful after the first install

## Projects

### [DOCSight](https://github.com/itsDNNS/docsight)

Self-hosted DOCSIS modem monitor for tracking cable signal problems, incidents, speed tests, and complaint-ready evidence.

Built for people who need more than a one-off speed test when their cable connection is unstable.

`Python` `Flask` `SQLite` `Docker` `Home Assistant`

### [tribu](https://github.com/itsDNNS/tribu)

Self-hosted family organizer for calm household planning. Shared calendar, tasks, shopping, contacts, birthdays, and reminders in one home base.

The goal is simple: keep everyday family coordination private, organized, and easy to use on the devices already around the house.

`Python` `FastAPI` `React` `Next.js` `PostgreSQL` `Docker`

### [TrueShot](https://github.com/itsDNNS/TrueShot)

Rotation overlay for World of Warcraft Midnight. It layers priority fixes on top of Blizzard Assisted Combat for Hunter, Demon Hunter, and Druid.

`Lua` `World of Warcraft AddOn`

### [DOCSight modules](https://github.com/itsDNNS/docsight-modules)

Community module catalog and development guide for DOCSight integrations.

`HTML` `Docs` `DOCSight`

## How I build

I prefer small, maintainable systems over heavy platforms. Good defaults matter. So do plain-language docs, screenshots that show the real product, and deployment paths that are boring in the best way.

If one of my projects solves a problem for you, feedback and bug reports are welcome.
